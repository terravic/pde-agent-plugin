## 4. Operations Escalated to Human Maintainers

1. **Shared Git History Cleanup (`C-002`):** Historical commits `fc077ab` (older compiled binaries containing local developer build path strings) and `4054da4` / `165d3bc` (historical `DESIGN.md` header) remain in git object history. Maintainers should run `git filter-repo` (or squash to a clean public release commit) before publishing git history externally.
2. **Legal Counsel Review (`L-001`):** Draft documents in `docs/legal/` are non-binding templates marked `DRAFT -- REQUIRES LEGAL REVIEW` and must be reviewed and finalized by qualified legal counsel before operational reliance.
3. **Cloud Endpoint Provisioning (`C-001`):** Teams using optional `pkde alphafold predict` or `pkde alphagenome` cloud backends must configure `PKDE_AF3_PROJECT`, `PKDE_AG_PROJECT`, `PKDE_AG_ENDPOINT_ID`, and `PKDE_AG_ENDPOINT_DNS` (pinned to EEA regions where required for data residency) and maintain appropriate Data Processing Agreements (DPAs) with their cloud provider.
